百谷长青 V1.20.1 · 本地试玩说明

Windows：完整解压，双击「百谷长青.exe」，并让同名 PCK 与 EXE 保持在同一文件夹。
网页：完整解压，安装有 Python 3 的电脑可双击「启动网页版.cmd」或运行 python serve_game.py。用支持 WebGL 2 的桌面浏览器打开 http://127.0.0.1:8115/，游戏期间保持启动器窗口开启。需要继续原发展时，使用同一浏览器和地址。

第一次玩：在野粮采集地派两人，建农专并派人领取农学札记，再建试验田并铺路。J 打开入门田课，G 铺路，B 建设，T 打开农学科技树。空格暂停，1、2、3 切换速度。
按 T 进入科技树。用顶部时代按钮、分支筛选或搜索定位课题，点节点在左侧看前置、衍生、投入和效果。第二个时代开始，可在右上角预览并确立一次专精。
五项现代田间项目需要农专工时和两个季末验收。每个有效季内至少有 8 秒，同时有农专教师和接通农专的农田劳力工作。可以跨存档继续。在课题详情内撤回项目会放弃原投入。
点击顶部「本季农情」查看当前天气。传统农耕阶段完成梯田或轮作路线中的一条即可满足路线要求。现代阶段将农专升建为农学院，建成农机学院，达标后投资合建中国农业大学，完工获胜。

营地足额发粮且有空床时，每季按人口的 5% 累计增长。新增居民从下一季起领粮。点农舍或人手面板的「编入农户」，可让一名现有居民参与农田和工地派工。
在「探险」页派两名空闲居民带回指定作物。每季季末也有 25% 的机会遇到带新作物种子的使者。选中任意农田可单独安排下茬，同一仓区的农田播种时从共用种粮中扣除各自用量。

Windows 存档写在 %APPDATA%\RiceByTheRiver\v1.20。首次点「继续」会优先读取本机 V1.19 发展，也兼容 V1.15 和 V1.10 发展。网页版使用浏览器在当前网址下的本机存储。

科技树可以用 WASD 或中键平移。必需前置使用实线，辅助科技使用虚线。掌握任一对应辅助科技，札记、物资和工时各减 20%，折后下取整，每项非零投入至少为 1。

口粮不足、新作物和季初自然事件会暂停时间。点击确认或选择应对后继续。同一时点的多条事件依次显示。自然事件按地区、季节抽取。


农业实践
在主菜单选择「农业实践」，可从长江中下游流域的丰年开始。跟着左侧提示完成八步练习，首收后返回主菜单。练习进度仅在本次会话保留。

调试控制台
进入发展或实践后，按 Esc 下方的 ~ 键打开控制台，直接按键或搭配 Shift 均可。也可以从游戏菜单进入。输入指令后按回车执行，再按 ~ 键或 Esc 关闭。指令作用于当前进度。
food 100         增加 100 份口粮
pop 5            增加 5 名居民
farmers 3        增加 3 名农户，优先编入现有居民
notes 10         增加 10 点札记
tech seed        完成当地的留种科技，可使用课题名或 ID
tech             完成在研课题
build            完成选中的工程。也可用 build E5 或 build all
event drought    触发旱灾。输入 event 可查看事件名称
discover 小麦    获得原种并显示小麦的农学分支
help             查看完整用法
