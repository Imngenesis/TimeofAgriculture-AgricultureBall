百谷长青 V1.15 · 本地试玩说明

Windows：完整解压，双击「百谷长青.exe」，并让同名 PCK 与 EXE 保持在同一文件夹。
网页：完整解压，安装有 Python 3 的电脑可双击「启动网页版.cmd」或运行 python serve_game.py。用支持 WebGL 2 的桌面浏览器打开 http://127.0.0.1:8115/，游戏期间保持启动器窗口开启。需要继续原战役时，使用同一浏览器和地址。

第一次玩：在野粮采集地派两人，建农专并派人领取农学札记，再建试验田并铺路。J 打开入门田课，G 铺路，B 建设，T 打开农学手册。空格暂停，1、2、3 切换速度。
第二个时代开始，手册右上角可确立一次专精。先预览四种方向的效果，再决定是否投入。点击「课题图」或课题名下的前置按钮，可以沿研究路线前后查看。
五项现代田间项目需要农专工时和两个季末验收。每个有效季内至少有 8 秒，同时有农专教师和接通农专的农田劳力工作。可以跨存档继续。在手册内撤回项目会放弃原投入。
点击顶部农时预报查看天气，安排防护。现代阶段将农专升建为农学院，建成农机学院，达标后投资合建中国农业大学，完工获胜。

Windows 的新存档写在 %APPDATA%\RiceByTheRiver\v1.15。首次点「继续」可读取本机 V1.10 战役，再保存到 V1.15 的目录。网页版使用浏览器在当前网址下的本机存储。
